# Système de recommandation de mode par image

> Computer Vision / Recommender System

## Vue d'ensemble

Projet de recommandation de produits de mode basé sur des fonctionnalités d'image. L'objectif est d'extraire des représentations visuelles et de proposer des articles similaires.

## Objectifs du projet

- Analyser des images de produits de mode.
- Extraire des features visuelles.
- Comparer les produits par similarité.
- Construire une logique de recommandation.

## Démarche

- Chargement du dataset de mode.
- Préparation des images.
- Extraction de caractéristiques.
- Recherche d’articles similaires à partir d’une image requête.

## Stack technique

- Python
- Jupyter Notebook
- Computer Vision
- Recommendation System
- Image Features
